# 游感周刊 · Playtrace

[打开游感周刊](https://zmperfect.github.io/playtrace-weekly/) · 每周选五款游戏。点「播放选段」就从选定的动作开始看，卡片给出建议观看范围和要留意的画面。首期的五个选段都在半分钟内。每款还附有两份具名测评或玩家点评，从中提炼玩法核心和吸引力，点来源可读原文。

首期使用哔哩哔哩玩家录像，以及本刊在《Admin》和《Riba》原版游戏中录制的无声短片。B 站播放器从选段起点开始，播过标出的终点后会继续原片。站内录像和 YouTube 选段使用播放器的结束位置。

每款游戏在「吸引力」下方附有一到两个原型点子。点开可以看到要保留的乐趣、改动的那条规则、最小可玩范围和试玩时值得观察的行为。单人一至两天的估时按使用熟悉的工具和占位素材计算。

## 历年游戏参考

[打开游戏库](https://zmperfect.github.io/playtrace-weekly/#library) 可以把历年参考作品和周刊选游放在一起找。第一批按 2007–2026 这二十个发行年份各选两款，共 40 款。选录看重一个可以从实机观察、也能在小原型里测试的设计，例如《陷阵之志》的敌方意图预告和《画中世界》的画格拼接。每款都附上开发者、发行商、原版手册或设计访谈等参考来源。

这 40 款各有一段 16–30 秒的玩家或赛事录像，点播放会直接定位到选中的操作。部分条目还可以切换到 Steam 官方短片。卡片里的「设计借鉴」和原型点子由周刊选编，出处可以用来对照原作的规则。

周刊首页的「按分类找游戏」列出各分类及收录数量。点一个标签即可浏览该类游戏，还可以按发行年份、中英文游戏名或具体机制缩小范围。复制地址即可分享当前筛选。历史条目采用原版首发或注明的正式版年份，跨平台移植、抢先体验等区别写在年份旁。周刊自动条目使用平台能核实的年份，缺少资料时会标为未知。

### 从游戏奖项找创意

[打开「奖项选游」](https://zmperfect.github.io/playtrace-weekly/#library?award=all) 可以按奖项、获奖或提名状态挑作品，再叠加玩法分类。比如先找解谜游戏，看《Baba Is You》怎样把通关规则变成可以推动的字块，再打开「原型点子」看看怎样把这个机制缩成一关。

奖项由编辑从主办方历年名单中选录。每条记录列出颁奖年份、具体奖项、获奖或提名状态，并链接到官方出处。游戏卡显示的发行年取自原作，两种年份可能不同。同一款作品可以有多项记录，在游戏库里只算一款。新收录的作品还附有具名媒体的「测评观察」，可以对照实机选段阅读原文，再试卡片上的单人原型点子。

## 更新方式

首期经过人工选编。之后 GitHub Actions 计划在每周一北京时间 09:07 采集。Steam 按官方热玩榜周排名变化选择，并读取商店简介。itch.io 选择热门网页 Game Jam 作品，保留作者原文。采集程序从玩法资料和评论中识别具体动作，匹配预先写好的原型点子。线索不足时，会给出一个用实机画面做预测小游戏的观察练习。每期优先收录三款 Steam 游戏和两款 itch.io 作品，避开最近四期的重复游戏。单一来源不足时用另一来源补足，凑不齐五款会保留已有期刊并报告失败。

后续期刊会优先选用作者标注的玩法章节，每段最多 30 秒。如果这款游戏也有 Steam 官方实机短片，可以在同一张卡上切换。缺少章节时，采集程序会寻找标为玩法演示的官方短片。只有完整实况时，页面会标明「暂无精选时间点」。自动收集的玩家评论以简短原文摘录展示，每段可追溯到具体评论。

每次采集成功后，GitHub Actions 会把更新后的网页发布到同一个 GitHub Pages 地址。可以在 [GitHub Actions](https://github.com/zmperfect/playtrace-weekly/actions/workflows/collect.yml) 手动运行。勾选 `preview` 只查看候选作品。同一周再次正常运行会保留已经发布的选编。

## 本地运行

在仓库根目录执行以下命令，然后打开 <http://localhost:4183>。

```shell
python -m http.server 4183 --bind 127.0.0.1 --directory dist
```

采集和目录生成使用 Python 3.11 或更高版本的标准库。

```shell
python scripts/collect.py --preview
python scripts/collect.py
python tools/update_reader.py
```

期刊档案保存在 [dist/data/issues.json](dist/data/issues.json)。前端是静态 HTML、CSS 和 JavaScript。作品配图及名称归各自权利人所有，选编卡提供作品和选录来源链接。
